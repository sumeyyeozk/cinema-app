# cinema-app
Bu github taki ilk projem
Bu proje, HTML, CSS ve JavaScript kullanılarak geliştirilmiş basit bir sinema bilet rezervasyon sistemidir. Kullanıcılar koltuk seçebilir, film seçebilir ve toplam tutarı görebilir.


Kullanılan Teknolojiler

HTML,
CSS,
JavaScript,
LocalStorage (veri kalıcılığı için)

Özellikler


 Koltuk seçme ve iptal etme
 Film seçme (fiyatla birlikte)
 Toplam koltuk ve ücret hesaplama
 LocalStorage ile seçimlerin kaydedilmesi
